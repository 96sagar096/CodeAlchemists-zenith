# CodeAlchemists Zenith

## Problem Statement

Campus administrations and civic authorities receive large volumes of complaints about potholes, garbage accumulation, water leakage, broken streetlights, and other infrastructure issues. Duplicate reports, incorrect categorization, uncertain severity, and inefficient resource allocation make it difficult to resolve the most critical problems first.

CodeAlchemists Zenith is an intelligent civic issue management platform that analyzes incoming complaints, identifies related incidents, estimates their urgency, and recommends appropriate actions. The platform helps administrators detect recurring problem areas, allocate resources efficiently, and track issue resolution across the complete complaint lifecycle.

## Technology Stack

- **Frontend:** React
- **Backend:** Spring Boot
- **Database:** MySQL
- **AI Integration:** Gemini API

## Project Structure

- React provides the user interface and client-side interactions.
- Spring Boot exposes the backend APIs and handles business logic.
- MySQL stores and manages application data.
- Gemini API provides AI-powered functionality where required.

## Key Features

- Submit and manage civic infrastructure complaints
- Automatically categorize incoming complaints
- Detect duplicate and related incident reports
- Estimate issue severity and urgency
- Recommend suitable actions and resource allocation
- Identify recurring problem areas
- Track complaints from submission to resolution

## Getting Started

### Prerequisites

- Node.js and npm
- Java and Maven
- MySQL
- A Gemini API key

### Running the Project

1. Clone the repository.
2. Configure the MySQL database in the Spring Boot application.
3. Add the Gemini API key to the backend configuration.
4. Start the Spring Boot backend.
5. Start the React frontend.
6. Open the application in a browser.
